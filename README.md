# Code Challenges

A collection of programming challenges used to practice problem solving, algorithms, data structures, and Java. Each
challenge includes its implementation and a short explanation of the approach, complexity, and important edge cases.

## Repository map

| Track                                                | Focus                                             | Challenges |
|------------------------------------------------------|---------------------------------------------------|------------|
| [AlgoExpert](src/algo_expert/README.md)              | Algorithmic patterns, beginning with arrays       | 3          |
| [Coding Challenges](src/coding_challenges/README.md) | Small exercises organized by topic and difficulty | 7          |

## How to use this repository

1. Choose a track above.
2. Open its section index to browse challenges by category and difficulty.
3. Read the challenge README before looking at the Java implementation.
4. Run or modify the implementation to test your understanding.

## Conventions

- Challenges are grouped by source or learning track, then by topic and difficulty.
- Directory prefixes such as `_01_` preserve a predictable study order.
- Each challenge README describes the problem, examples, approach, complexity, and relevant edge cases.
- Implementations are written in Java unless a challenge states otherwise.

## Current coverage

- AlgoExpert arrays: two-number lookup, subsequence validation, and sorted squared arrays.
- Coding Challenge arrays: one-level list flattening, inclusive range counting, counting values above average, and consecutive duplicate grouping.
- Coding Challenge strings: character lookup, prefix matching, and whitespace trimming.

The collection is intentionally incremental; new challenges can be added under the appropriate track and linked from the
nearest section README.
