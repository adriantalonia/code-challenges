# String Challenges: Easy

Beginner string exercises focused on direct character comparison, validation, and early termination.

| # | Challenge                                                                 | Concept                                 | Complexity                                            |
|--:|---------------------------------------------------------------------------|-----------------------------------------|-------------------------------------------------------|
| 1 | [Contains Character](_01_contains_character/README.md)                    | Two-pointer character search            | `O(n)` time, `O(1)` space                             |
| 2 | [Starts With Prefix](_02_starts_with_prefix/README.md)                    | Direct prefix comparison                | `O(m)` time, `O(1)` space, where `m` is prefix length |
| 3 | [Remove Leading and Trailing Whitespace](_03_remove_whitespace/README.md) | Two-pointer boundary scan               | `O(n)` time, `O(1)` auxiliary space                   |
| 4 | [Palindrome Check](_04_is_palindrome/README.md)                           | Case-insensitive two-pointer comparison | `O(n)` time, `O(1)` space                             |
